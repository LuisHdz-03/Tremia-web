# <img src="https://api.iconify.design/ph:trophy-bold.svg?color=%2338C2FF" height="32" valign="middle"/> Tremia (Ecosistema Web & Mobile) - Innovation Fest 2025

**Proyecto Ganador del 3er Lugar en el Innovation Fest 2025.** 
Tremia es una solución tecnológica integral diseñada para conectar, activar y dinamizar comunidades empresariales y organizaciones. Este repositorio funciona como el portafolio central del ecosistema, el cual está compuesto por una aplicación móvil para los usuarios (socios y empresas) y un panel de administración web para la moderación de la plataforma.

## <img src="https://api.iconify.design/ph:sparkle-bold.svg?color=%2338C2FF" height="28" valign="middle"/> Características del Ecosistema

*   **Matchmaking Inteligente (Mobile):** Sistema de conexión basado en intereses y perfiles (Innovación, Tecnología, Salud, Educación) para vincular socios con organizaciones y eventos relevantes.
*   **Integración de Asistente IA (Mobile):** Implementación de "Trimi", un agente inteligente diseñado para guiar a los usuarios, mejorar la interacción y brindar soporte automatizado dentro de la comunidad.
*   **Gestión de Accesos (Web):** Módulo centralizado de *Gatekeeping* para aprobar o rechazar solicitudes de entrada a la comunidad, garantizando un entorno exclusivo y seguro.
*   **Moderación en Tiempo Real (Web):** Interfaz de supervisión para administrar foros, visualizar hilos de discusión y mantener el control sobre las organizaciones y usuarios registrados.

## <img src="https://api.iconify.design/ph:code-bold.svg?color=%2338C2FF" height="28" valign="middle"/> Stack Tecnológico

Al ser una solución completa de extremo a extremo, el ecosistema requirió tecnologías modernas para cada una de sus capas:

*   **Backend as a Service (BaaS):** Firebase (Autenticación, base de datos en tiempo real y almacenamiento unificado para todo el ecosistema).
*   **Aplicación Móvil:** React Native / Expo (Interfaces dinámicas y consumo de APIs).
*   **Panel Administrativo (Frontend):** React.js / Next.js con Tailwind CSS.
*   **Lenguaje Base:** JavaScript / TypeScript.
